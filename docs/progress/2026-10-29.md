# 2026-10-29：VSCode 操作录制与逐台验证

## 本次完成

新增 `harmonyos-bridge` 本地通信入口，复用已有的设备会话锁、HarmonyOSDriver、Maestro 和 Orchestra。VSCode 插件通过标准输入输出连接该进程，获取截图和控件树，执行动作并接收相应 YAML。动作成功后才追加步骤，保存为标准 Flow；回放前先断开录制会话。

插件 0.1.0 提供设备选择、截图点选、控件树、点击、输入、滑动、返回、可见断言、截图、保存和回放。它只记录插件内发出的操作，不监听手机手工触摸。屏幕尺寸变化后需重新连接；嵌套或未闭合的 `${...}` 若不能无损保存，会明确拒绝。

新增逐台验证脚本，按显式设备列表和计划轮次顺序执行同一套 Flow，每轮单独保存产物。报告包含真实退出码、未执行原因、设备环境、输入文件及主要实现 JAR 的指纹。探测到工具存在只记为 `available-unverified`，不会据此声明所有命令或视频录屏可用。

## 联调发现及修复

- 初次快照失败。成对采集布局后确认，变化来自系统状态栏网速文字，应用控件未变化。现在仅排除已识别且不覆盖应用的状态栏子节点动态内容，保留窗口自身的属性、几何和出现/消失检查；状态栏不提供录制点选。弹窗、键盘和未知窗口继续检查。
- 第二次在原有全局稳定等待阶段超时。录制快照改为自身最多 20 秒的只读采样，连续布局一致后截图并再次核对。此修改没有重试点击或输入，也没有更改共享驱动的等待行为。首次两次失败日志和对比布局保留在 `artifacts/recorder/`。
- 复核发现停止按钮可能与连接或回放准备竞争。现以取消信号和会话世代检查阻止迟到响应恢复连接、追加步骤或启动回放；通信超时会清理连接状态，保留已录步骤并允许重连。相应回归已加入扩展测试。
- 脚本首次在 Windows PowerShell 5.1 暴露测试夹具的 UTF-8 读取和长路径问题。修复后两种 PowerShell 均通过，首次日志保留，未替换失败记录。

## 智能体接口两批实现

本次补充实现[智能体调用协议 v1](../agent-protocol.md)。原五方法继续供 VSCode 使用，新增十个 `agent.*` 方法，覆盖能力与环境查询、会话、快照、动作、取消、释放、结果和证据读取。CLI Flow 与矩阵共用结果格式；没有另建 YAML 执行器。

尝试在派发前持久登记，输入归档及指纹参与查重。同一输出根内，重复提交相同 `attemptId` 被拒绝，换 `runId` 也不能复用该尝试标识。恢复丢失执行进程的未完成记录时保留未知。每次实际执行步骤有独立 `stepId`，循环和重试不覆盖旧步骤，源位置另存。失败步骤能查到截图、布局、日志和命令产物；取不到材料时明确记为缺失或采集失败。

环境预检只读，静态支持声明不代表当前设备已经验证。本机未找到可靠的只读锁屏判断，因此 UI 命令预检的对应检查保留 `unknown`。修改操作的副作用保守记录为 `possible`，不把进程退出码当作业务效果已经确认。

取消与执行分开处理。受理取消后停止新增动作，清理结果未确认时不允许交接；矩阵遇到未知清理也停止该设备后续计划轮次。正常释放后，后续 CLI 仍须实际取得设备锁。

### 本轮真机结果

在现有一台测试手机上完成：能力查询、只读预检、启动测试应用、快照与可见断言、截图、重复尝试拒绝、预期断言失败及证据查询。普通动作和失败断言收尾后，释放会话返回 `closed`、`cleanup=complete`、`handoffReady=true`；随后的真实 CLI Flow 成功取得设备并执行，退出码 0，摘要、JUnit 和证据索引均生成。未点击登录、注册或业务提交按钮。

首次活动取消测试暴露了一处实现问题：取消回执已受理，但只中断会话线程，没有停止协程 IO 线程中的设备等待，约 18 秒后误报普通断言失败并允许交接。原材料保留在本地 `artifacts/agent-v1-device-1793269433567/`，没有用后续成功覆盖。

修复将尝试的取消请求绑定到实际执行协程，同时保留执行器吞掉取消时的未知清理保护。复测的取消回执耗时 46 毫秒，最终结果为 `cancelled / CANCELLED`；会话线程退出、主机锁释放后，远端收尾仍记为 `unknown`，`handoffReady=false`，桥接退出码 1。没有在这次未知清理后继续自动操作设备。完整复测材料位于本地 `artifacts/agent-v1-device-1793270589225/`。

本轮验证了单台手机上的接口行为，没有增加第二台设备兼容或长期稳定性结论。远端命令和临时资源被中断后的自动确认清理仍未提供；当前通过保留未知并阻止接管处理这一边界。实验性视频录屏的既有限制不变。
