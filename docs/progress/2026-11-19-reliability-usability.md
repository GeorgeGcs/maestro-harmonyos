# 驱动回归、键盘和预览验证

更新于 2026 年 11 月 19 日 17:19。以下为源码分支的实现与验证，现有 v0.1.3 下载包不包含这些改动。测试使用 Windows、JDK 17 与 API 22 鸿蒙模拟器。

## 实现范围

| 项目 | 修改 |
| --- | --- |
| Windows CI | 保留精简主机测试，增加完整鸿蒙驱动、传输和编排测试。逐模块归档 JUnit，并核对必测类、失败和跳过项。真实 Shell 清理测试显式使用 Git Bash。 |
| 源码 fork | 将可构建源码同步到 `969b2cebe6dbbbe86a986e7fd48fc9acf6460bff`。`source-fork.lock.json` 固定输入；校验器使用独立 Git 索引比较完整源码树，保留开发者工作文件与暂存区。 |
| 使用说明 | 更新平板完整套件记录、CI 范围和启动 Ability 自动发现说明，新增键盘命令的使用条件。 |
| `hideKeyboard` | 识别可见输入法窗口后只发送一次返回；等待键盘隐藏，并检查目标应用仍持有焦点。键盘已隐藏时直接返回。示例见 [05-hide-keyboard.yaml](../../examples/component-collection/flows/05-hide-keyboard.yaml)。 |
| 预览采集 | 后台优先获取最长边 960 像素的 PNG，复用到预览和主机录像。显式截图保留原尺寸。设备明确拒绝缩小截图时回退原后端；超时不盲目重发。 |
| 窗口解析 | 按列名解析窗口 ID、进程和键盘状态，覆盖列顺序变化及带空格的窗口名。启动时焦点记录与窗口表短暂不一致会继续等待；未知表格式、重复焦点和归属冲突明确报错。 |

## 模拟器验证

`hideKeyboard` Flow 用时约 1 分 1 秒：打开官方示例输入页，通过 `test_input` 控件 ID 输入文字，保存键盘可见截图，收起键盘，断言文字与当前页面，再调用一次并检查页面仍保留。前后截图确认键盘确实隐藏，结果为 `passed`、`cleanup=complete`。

首次尝试被输入法初始化协议页阻塞；经授权完成专用模拟器输入法初始化后，使用控件 ID 的独立用例通过。通用用例不自动接受系统或输入法协议。

| 预览与录像场景 | 结果 | 耗时 |
| --- | --- | ---: |
| 开启预览和主机录屏，切换四次标签并显式截图 | 通过，10 次预览更新；MP4 13 帧全帧解码通过；清理完成并释放设备。 | 63.07 秒 |
| 预览更新后请求停止 | `cancelled`；MP4 3 帧全帧解码通过；清理完成并释放设备。 | 22.87 秒 |
| 同场景增加 6 秒无设备动作等待 | 通过，13 次预览更新；MP4 19 帧全帧解码通过；清理完成并释放设备。 | 63.29 秒 |

原后端的相应等待场景为 68.71 秒、12 次预览更新和 19 帧录像。该组测试期间还在执行主机回归，不能据此推算整体 Flow 的稳定提速比例。

### 单帧采集对照

同一静态页面交替调用原尺寸截图与缩小预览，各预热一次，再各采集三次。下表包含设备采集、文件传输与临时文件清理。

| 方式 | PNG 尺寸 | 文件大小 | 采集耗时中位数 |
| --- | --- | ---: | ---: |
| 原尺寸截图 | 1256 × 2760 | 224,415 字节 | 999 ms |
| 缩小预览 | 436 × 960 | 44,275 字节 | 934 ms |

该页面的数据量减少约 80.3%，采集耗时缩短约 6.5%。三次原尺寸结果为 999、990、1034 ms，预览为 902、982、934 ms。这是单设备、静态页面的短测；预览仍是按需 PNG 采样，未承诺持续视频帧率。
