1. 创建公开远端仓库，推送启动材料，按活动组指引配置招募小助手权限。
2. 登记测试设备型号、系统/API 版本及工具版本；设备标识保留在本地。

4. 完成 M1 最小流程，优先暴露中文输入、滚动后定位、视频录屏和状态重置问题。
5. 如发生延期或范围变化，记录原因、影响与调整，不修改历史记录伪装按期完成。
