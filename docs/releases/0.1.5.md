# Maestro HarmonyOS v0.1.5

Windows CLI、VS Code Recorder 0.1.5 和便携包使用同一份适配源码。CLI 沿用上游 Maestro 版本，`maestro --version` 返回 `2.12.0`。附件的源码提交、字节数和 SHA-256 见 `release-manifest.json` 和 `SHA256SUMS`。

## 更新内容

- **点击前少取一次树。** 常规控件点击复用已完成的定位，取得新布局后确认目标身份、窗口和可点击范围。同一台 API 26 手机上，HDC 点击耗时中位数由 **12.14 秒降至 10.01 秒**。显式变化重试仍比较画面。
- **连续断言复用布局。** 带 `childOf` 的正向断言可在 250 毫秒内复用命中的树。同机三组对照中，每轮取树从 3 次减至 1～2 次，三条断言的耗时中位数由 **7.13 秒降至 4.29 秒**。负向断言、含 CSS 的选择器和缓存未命中继续实时查询。
- **减少 ArkWeb 重复核验。** 显式 WebView 目标可对同一连接内两秒内的相邻读取复用一次转发核验。每次仍读取新 DOM 并核对页面。在 API 22 双 WebView 样例中，核验次数从 **8 次减至 4 次**，滑动耗时仍约 5.1 秒。 [性能验证条件](../progress/2026-11-24-query-performance.md)
- **接入前检查。** VS Code 的「HarmonyOS: 检查运行环境」和 `scripts/doctor.mjs` 可检查设备、应用和 UITest。RPC 监听检查只读，实际取树后端及回退原因记入 `maestro.log`。 [预检用法](../user-guide.md#首次运行预检)
- **离线打开失败证据。** 对结束的运行导出 HTML 或 ZIP，查看失败 YAML 行、步骤截图、日志末尾和设备清理状态。 [导出用法](../user-guide.md#离线查看运行证据)
- **主机录像可选去重。** 默认保留连续相同帧。设置 `MAESTRO_HARMONYOS_HOST_RECORDING_DEDUPLICATE_FRAMES=true` 可合并相同帧，并保留静止画面的停留时长。显式截图仍保存原尺寸。
- **收尾和结果查询。** 修复证据归属核验和指定旧版诊断任务的恢复。证据不足时仍按会话规则隔离设备。 [恢复条件](../legacy-diagnostic-recovery.md)

## 安装

1. 已有 JDK 17 和 HDC 时，下载 Windows CLI ZIP，用 `Get-FileHash -Algorithm SHA256 <文件>` 核对 `SHA256SUMS` 后解压。启动器位于 `bin/maestro.bat`。
2. 在 VS Code 选择「从 VSIX 安装」，将 `harmonyosRecorder.cliDirectory` 指向新 CLI 根目录。如已配置旧版 CLI 路径，升级插件后也要更新这个设置。
3. 需要 CLI、脚本、示例和项目源码一起使用时，下载便携 ZIP。它已包括同一套 CLI，无需同时下载独立 CLI ZIP。CLI 位于 `cli`，脚本与示例位于 `source`。VSIX 单独下载。
