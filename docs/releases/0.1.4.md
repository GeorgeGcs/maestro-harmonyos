# Maestro HarmonyOS v0.1.4

适配版提供 Windows CLI、便携包和 VS Code Recorder 0.1.3。CLI 沿用固定的 Maestro 上游版本，`maestro --version` 返回 `2.12.0`。适配仓提交、附件大小与 SHA-256 以 `release-manifest.json` 和 `SHA256SUMS` 为准。

## 本版变化

- 支持标准 YAML `hideKeyboard`。检测到目标应用的软键盘后发送一次返回，再检查键盘已隐藏且应用仍有焦点。键盘已收起时可重复调用。VS Code 提供命令补全，Agent 也能在预检中识别该命令。
- 按列名读取窗口归属。应用启动时如果窗口表尚未跟上焦点变化，驱动会继续等待。窗口表格式或归属无法确认时，错误信息会指出原因。
- 后台预览优先使用最长边 960 像素的 PNG，与主机录屏共用采集通道。显式截图仍保留原尺寸。API 22 模拟器静态页面的短测中，单帧从 224,415 字节降至 44,275 字节，采集中位数从 999 ms 降至 934 ms。 [测量条件](../progress/2026-11-19-reliability-usability.md#单帧采集对照)
- Windows CI 增加完整驱动、编排、YAML 集成和 CLI 会话回归，按模块归档 JUnit。构建会核对源码 fork 与交付补丁生成的完整源码树。

## 安装

1. 下载对应的 ZIP、VSIX 和 `SHA256SUMS`。在 Windows 使用 `Get-FileHash -Algorithm SHA256 <文件>` 验证下载文件，再解压到新目录。
2. 单独使用 CLI 时，配置 JDK 17 和 HDC 后，从解压目录运行 `bin/maestro.bat`。便携包的 CLI 位于 `cli`。
3. 在 VS Code 选择“从 VSIX 安装”，安装插件 0.1.3。将 `harmonyosRecorder.cliDirectory` 指向新 CLI 的根目录。
