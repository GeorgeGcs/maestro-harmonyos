# Maestro HarmonyOS v0.1.3

本版包含 Windows CLI、VS Code 插件 0.1.2 和便携包。CLI 沿用 Maestro 上游 `3fc4ef3fc408bc70ea9baf0bac0ff3e4b565710c`，运行 `maestro --version` 显示 `2.12.0`。适配仓提交、附件文件名和校验值以发行页随附的 `release-manifest.json` 和 `SHA256SUMS` 为准。 [GitCode 发行页](https://gitcode.com/HarmonyPandaWorkshop/maestro-harmonyos/releases)

## 本版变化

- 标准 YAML 给出 `appId` 即可尝试发现主 Ability。已有显式设备、Ability、模块和 RPC 配置可以继续使用。
- VS Code 按录制时的控件树核对 ID、文字及匹配数量。执行面板显示当前步骤和重试次数，可打开失败 YAML 行、截图和日志。停止并确认设备释放后可重跑。
- 主机录屏和 VS Code 预览共用设备截图采集。ArkWeb 支持显式选择多个 WebView 中的页面，发现错配或旧进程时使用原生控件树。
- CI 和鸿测 Worker 可以共用设备占用目录，按设备类型、系统和 API 筛选。清理结果未知时，设备留待核查。
- 新增 `openLink` 和图库媒体导入，补充 `clearState` 与 `setOrientation` 的设备限制。 [命令支持表](../user-guide.md#当前支持范围)

## 安装与升级

下载便携包，先用 `Get-FileHash -Algorithm SHA256 <文件>` 对照 `SHA256SUMS`，再解压到新目录。VS Code 安装本版的 VSIX 0.1.2，将 `harmonyosRecorder.cliDirectory` 指向随包的 `cli` 目录。旧会话的设备隔离按原有恢复记录处理。 [使用指南](../user-guide.md) · [演示入口](../demo.md) · [会话恢复](../cleanup-fence-recovery.md)
