## 快速使用

下载后，在 PowerShell 中执行 `Get-FileHash -Algorithm SHA256 <文件路径>`，与 `SHA256SUMS` 核对。便携包还可使用仓库的 `scripts/verify-agent-bundle.mjs` 解压核验，完整命令见源码中的 `docs/agent-bundle.md`。

便携包解压后，在 `source` 目录执行已有 Flow，使用 `-CliDir ../cli` 指向随包 CLI。例如，安装并准备 HMOS 代码工坊的 phone 应用后：

```powershell
$env:MAESTRO_HARMONYOS_HDC = 'C:/tools/hdc.exe'
$env:MAESTRO_HARMONYOS_RECORDING = 'off'
./scripts/run-harmonyos.ps1 -CliDir ../cli `
  -FlowPath ./examples/hmos-code-lab/flows/suite `
  -BundleId com.huawei.hmos.sample -AbilityName EntryAbility -Module phone `
  -DeviceId YOUR_DEVICE_ID -RunTimeoutSeconds 1320
```

替换 HDC 路径和设备标识，设置本机 `JAVA_HOME`；设备需解锁、完成首次引导并保持测试应用前台。应用获取与调试签名说明在源码 `examples/hmos-code-lab/README.md`。

VSCode 中选择“从 VSIX 安装”，将 `harmonyosRecorder.cliDirectory` 设置为便携包的 `cli` 目录或独立 CLI 的解压目录，另填本机 Java、HDC 路径。
