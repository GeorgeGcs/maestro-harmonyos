## 运行

使用固定版本的 [HMOS 代码工坊](../../README.md)，安装 `phone` 模块，完成首次引导，界面使用简体中文。运行期间不要操作设备。每轮启动保留应用进程，先确认根页面中选中的标签，再切到“组件”；不把未选中的底栏文字当成组件页面已就绪。

若上轮留在本套件详情页，入口会关闭已打开的警告弹窗，仅在“预览区域”可见且不存在选中的根标签时执行最多 3 次返回，用于收起输入法并返回列表。无法识别的页面保留失败，不盲目返回或退出应用。此恢复处理不会改写上一轮结果。

列表导航使用 `scrollUntilVisible` 的 `centerElement: true`。当前 Maestro 版本的居中判断只检查滚动方向对应的一侧：向下查找后，补一次从屏幕 `50%,40%` 到 `50%,55%`、持续 1000 ms 的短距离向下滑动，将目标移出顶部标题栏区域；向上查找保留 `UP → DOWN` 的两次检查。查找和点击同时限定目标在已选中的组件标签上方。

此处理不提供通用遮挡检测。`above` / `below` 只比较节点左上角的 y 坐标，不检查两个矩形是否重叠；`below: { id: HdsTitleBar }` 无法排除本次四个顶部点击位置。`centerElement` 超过居中重试上限后仍可按屏幕内可见比例成功返回，UITest 的 `visible=true` 也不代表未被覆盖。短滑的实际位移受页面滚动边界和惯性影响；修改后须重新验证具体场景，不能将这些条件当作点击安全保证。

```powershell
$env:MAESTRO_HARMONYOS_RECORDING = 'off'
./scripts/run-harmonyos.ps1 `
  -FlowPath ./examples/hmos-code-lab/flows/suite `
  -BundleId com.huawei.hmos.sample -AbilityName EntryAbility -Module phone `
  -DeviceId YOUR_DEVICE_ID -RunTimeoutSeconds 1320
```

示例限时为 1320 秒，为完整套件执行及正常收尾留出余量。

| 场景 | 操作与检查 | 完成后的状态 |
|---|---|---|
| 输入 | 从列表进入单行文本输入，确认焦点，通过参数输入“鸿蒙测试”，断言并截图 | 清空本流程写入的 4 个字符，返回列表 |
| 按钮 | 进入按钮页，切换到 `Textual`，断言并截图 | 恢复 `Emphasized`，返回列表 |
| 弹窗 | 打开警告弹窗，断言标题、正文和两个按钮，截图后关闭 | 返回列表，定位到单行文本输入入口 |

输入参数与清空字符数对应，修改 `INPUT_TEXT` 时需同步调整 `common/input.yaml` 的 `eraseText`。任一步骤失败会保留失败结果；不要把失败轮中途的手动操作记作自动执行成功。
